
# 💗 Yolanda Mbande | Developer Portfolio

A colourful, playful, and interactive personal portfolio showcasing my journey as a Junior Software Developer.

Built with a pink neo-brutalist aesthetic, bold typography, interactive elements, and a little personality. Because developer portfolios don't have to be boring! ✨

## 🌐 Live Website

🔗 [View My Portfolio](https://yolandambande.github.io/)

> Update this link with the GitHub Pages URL for this repository.

## ✨ Features

- 💗 Pink neo-brutalist design with bold borders and shadows
- 📱 Responsive layouts for desktop, tablet, and mobile
- 🎠 Interactive project carousel with Next/Previous navigation
- 📸 Personal profile photo
- 💼 Professional experience and education
- 🛠️ Technical skills and tools
- 📄 Viewable and downloadable CV
- 📋 Copy-to-clipboard email functionality
- 🎨 Animated stickers, hover effects, and playful typography
- 🔗 Links to live projects and GitHub repositories

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome
- Google Fonts
- GitHub Pages

## 💻 Running Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use Live Server.
4. Explore the portfolio!

No build process is required.
